# 数学建模竞赛论文与源程序全量仓库 (Mathematical Modeling Repository)

本仓库包含 **水泥烧成系统电除尘器的协同优化控制** 数学建模竞赛全套论文、评审报告、数据分析、全量源程序与交付产物。项目结构划分为两大核心类别：

---

## 📁 01_论文过程研讨与评审报告 (Process & Review Reports)

包含论文自开题、数据审计、多轮模型迭代至专家评审的完整研讨与审查报告：

- **00 ~ 04 研讨报告**：题意拆解、文献检索矩阵、论文大纲与完整初稿。
- **05 ~ 09 评审报告**：学术完整性核验、五席独立专家评审、CUMCM 国奖标准打分报告。
- **10 ~ 16 迭代记录**：第一轮/第二轮修改追踪、逐点回复与终稿复审报告。
- **辅助材料**：`AI工具使用详情.md`、`review/` 与 `revision_round1/`。

---

## 📁 02_最终论文与代码交付包 (Final Paper & Source Code Deliverables)

包含符合 CUMCM 国奖标准的最新终稿论文、高清 PDF 导出包、全量 Python 源码及自动化核验工具：

- **论文终稿 Markdown**：[`10_修订后完整论文_终稿.md`](02_最终论文与代码交付包/10_修订后完整论文_终稿.md)
- **PDF 终稿导出包**：
  - [`终稿/10_修订后完整论文_终稿.pdf`](02_最终论文与代码交付包/终稿/10_修订后完整论文_终稿.pdf) *(67 页全量舒展版，摘要独占首页)*
  - [`终稿/水泥烧成系统电除尘器的协同优化控制_匿名终稿.pdf`](02_最终论文与代码交付包/终稿/水泥烧成系统电除尘器的协同优化控制_匿名终稿.pdf) *(匿名提交版)*
- **图表集 (`figures_paper/`)**：21 幅出版级 PNG 预览与 PDF 矢量图表。

  - `scenario_model.py`：工况聚类、二次岭功耗模型与灰箱情景优化。

  - `plot_utils.py`：出版级绘图样式库。
  - `integrity_check.py`：57 项自动化确定性核验工具 (100% PASS)。
- **求解数据 (`results/`) & 自动化核验 (`integrity/`)**。
