按题目分目录存放论文、评审记录、源程序与交付产物。每个题目一个顶层目录，目录内自成体系，互不依赖。

## 目录约定

新增题目时按同样的结构建立顶层目录：

```
<题号>/
├── README.md                  题目说明与交付索引
├── 03_论文过程研讨与评审报告/    开题、数据审计、多轮评审与修订记录
└── 04_最终论文与代码交付包/      终稿、图表、源程序、结果数据与交付产物
    ├── src/                   可运行源程序
    ├── data/  results/        处理数据与求解结果
    ├── figures_paper/         正文图件（PNG 预览＋PDF 矢量）
    ├── integrity/             确定性核验结果
    └── build/                 LaTeX 中间产物与编译输出
```

各题目录内的源程序均以自身所在位置定位数据与输出（`Path(__file__).resolve().parents[1]`），
因此目录整体移动或改名不影响复现；跨题目录之间没有共享路径。
