# 数据审计结论（阶段 1）

脚本：`04_最终论文与代码交付包/src/audit_attachment.py`
结果：`04_最终论文与代码交付包/results/data_audit.json`

先看数据再建模。附件里藏着四件事，每一件都改变了后面的模型。

## A1 附件的一行不是一根介质，而是一个碎片

按题面，介质 A 的轴长恒为 5000 nm。但附件里绝大多数行的两端点距离都小于 5000：

| 组 | 行数 | 行长为 5000 的比例 | 总轴长 / 5000 |
|---|---|---|---|
| 组1 | 12 | 2/12 | 6.85 |
| 组2 | 49 | 11/49 | 27.85 |
| 组3 | 535 | 155/535 | 351.21 |

把同轴向（方向向量完全相同）的行归为一组后，组数分别是 **7 / 28 / 354**，且每组的
轴长之和都不超过 5000。结论：**一行是边界截断之后的一个碎片，一组同向的行才是一根母介质**。

组 3 的 354 根对应体积分数 0.5005%，正好是问题二要求的第一档 0.50%——这既确认了还原是对的，
也说明组 3 就是按问题二的口径生成的。

## A2 组 1、组 2 的周期盒不是 10000³

碎片首尾在边界处成对出现（前一碎片终点在 +h，后一碎片起点在 −h，其余两坐标完全相同）。
按这个特征反查回绕面的位置：

- 组 3：x、y、z 都在 ±5000 回绕 → 10000³，与题面一致；
- 组 1、组 2：x 在 ±5000 回绕，但 **y、z 在 ±500 回绕** → 截面只有 1000×1000 nm。

所以组 1、组 2 是"细长通道"而不是题面的立方体，体积分数分别是 0.99% 和 3.96%。
问题一必须按各自的实际几何判定，不能套用 10000³。

## A3 附件系统性丢弃了短碎片

把每根母介质的碎片接起来，长度应当恰为 5000。组 3 有 49 根接不满，缺口分布为：

- 46 根缺口 < 500 nm（最小 1 nm）；
- 3 根缺口分别为 636 / 732 / 870 nm——这三根各缺了两个碎片。

而附件中**保留的最短碎片是 526 nm**。因此：所有被丢弃的碎片单个长度都小于 500 nm。

风险：被丢弃的碎片有可能正好是一座桥。处理办法是把缺失碎片按几何反推补回去再判一次
（`solve_p1.py` 的 `restored` 口径），三组结论都不变。

## A4 方向分布不是各向同性——本题影响最大的一条

组 3 的 354 根母介质，方向余弦绝对值的均值是

```
E|u| = (0.656, 0.390, 0.394)
```

各向同性应当是 (0.5, 0.5, 0.5)。以 X 轴（带电面法向）为极轴、θ~U(0,π)、φ~U(0,2π) 的分布
理论值是 (2/π, (2/π)², (2/π)²) = (0.637, 0.405, 0.405)。

对 |u_x| 做 KS 检验：

| 假设分布 | D | p |
|---|---|---|
| 球面均匀（各向同性） | 0.243 | 6.7e-19 |
| θ~U(0,π)，极轴为 X | 0.036 | 0.73 |

各向同性被断然拒绝。这是生成器在球面采样时的经典写法差异（直接对极角均匀采样会在两极堆积），
但后果很实在：介质明显偏向带电面法向，**同一体积分数下的导通概率几乎翻倍**
（φ=0.50% 时 0.219 vs 0.087）。

组 1、组 2 的 E|u_x| 高达 0.997 / 0.994，几乎完全沿 X 轴——它们是为问题一专门构造的算例，
不能用来标定问题二的分布。

## 采用的口径

问题二至四以**附件标定分布**（θ~U(0,π)，极轴 X）为主口径，因为它是唯一有数据支持的生成规则，
并且它让"组 3 在 φ=0.50% 下导通"成为一个 22% 概率的正常事件而不是巧合。
球面均匀作为对照口径全程并列给出。
