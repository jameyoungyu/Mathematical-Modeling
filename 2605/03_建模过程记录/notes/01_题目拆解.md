# 题目拆解（阶段 0）

赛题：2026 年第七届"华数杯"A 题 · 微构体中填充导电介质的仿真优化

## 一、一共问了几问，每问要交付什么

| 问 | 要求交付 | 形态 |
|---|---|---|
| 1 | 附件三个微构体分别是否导通 | 三个二值判定 + 判定依据 |
| 2 | 只填 A，φ=0.50%/0.60%/0.70%/1.00% 各自的导通概率 | 四个概率（带不确定度） |
| 3 | 只填 A，使导通概率 ≥90% 的最低体积分数 | 一个百分数，精确到 0.01% |
| 4 | A、B 混填，P≥90% 下总成本最低的填充量 | (N_A, N_B) 或 (φ_A, φ_B) + 成本 |

四问全部围绕同一个判定内核：**给定一组介质的位姿 → 是否导通**。因此工程上先把内核做对做快，
四问都是内核的不同用法（一次判定 / 频率估计 / 反解阈值 / 带约束优化）。

## 二、每问的输入

- 问 1 输入：附件 xlsx 的三个分表（坐标已给定，无随机性）；
- 问 2–4 输入：题目给的几何常数与随机生成规则。**生成规则是自己设定的，不是题目给死的**，
  这正是最需要小心的地方——附件是唯一能反推组委会生成器的证据（见 `02_数据审计结论.md`）。

几何常数：微构体边长 10000 nm；介质 A 直圆柱 h=5000、r=30；介质 B 球 R=200；
导通判据：表面最短距离 ≤1.8 nm；带电面为垂直于 X 轴的两个面（x=±5000）。
成本：A 1.05 元/μm³，B 0.05 元/μm³。

## 三、问题之间的依赖

```
问1 判定内核 ──> 问2 频率估计 ──> 问3 对 φ 反解 ──> 问4 加入介质 B 后的带约束优化
        ↑
   附件数据审计（确定生成器：周期盒、方向分布、碎片口径）
```

关键依赖：**问 1 不只是"送分题"**。它是唯一能校准问 2–4 随机生成器的锚点。
如果直接假设"方向各向同性"去做问 2，得到的概率与附件所隐含的分布相差近一倍。

## 四、题型判断

- 问 1：几何计算 + 图连通性判定（确定性）；
- 问 2、3：随机几何 / **连续渗流**（continuum percolation）的蒙特卡洛估计；
- 问 4：以蒙特卡洛为约束函数的**整数规划**，目标线性、约束单调 → 最优解落在可行域边界，
  可降为一维搜索。

不是优化题的常规套路（LP/MILP 直接建模不适用），因为约束 P(N_A,N_B)≥0.9 没有解析式，
只能通过仿真估计，属于"仿真优化"（题目标题即点明这一点）。

## 五、必须先定清楚的三件事（否则模型无意义）

1. **边界截断后，一根介质被切成的多个碎片，电学上算一个还是各算一个？**
   → 各算一个（题面"截断"的字面含义；由用户确认；并且这是唯一能让问 1 三组给出不同答案的口径）。
2. **周期盒有多大？** → 组 3 是 10000³；组 1、组 2 的 y、z 在 ±500 回绕，截面仅 1000×1000。
3. **方向分布是什么？** → 附件服从"以 X 轴为极轴、θ~U(0,π)"，不是球面均匀。

三条都由附件数据定，不能靠猜。
