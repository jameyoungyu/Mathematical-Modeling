# 支撑材料文件清单

对应论文《微构体中填充导电介质的仿真优化》。所有结果均由 `src/` 下的脚本一次跑出，
论文中的每个数值都能在 `results/` 里找到出处。

## 一、源程序（`src/`）

| 文件 | 作用 | 对应论文位置 |
|---|---|---|
| `microstructure.py` | 几何与渗流内核：边界截断、球柱体最短距离、KD 树邻域检索、并查集导通判定 | 第 3 节 |
| `load_attachment.py` | 读附件、按轴向把碎片还原为母介质 | 第 2.1 节 |
| `simulate.py` | 蒙特卡洛驱动：并行、Wilson 区间、SeedSequence 可复现 | 第 5.1 节 |
| `audit_attachment.py` | 数据审计与方向分布的 KS 检验 | 第 2 节，图 1、图 2 |
| `validate.py` | 几何内核 6 项独立校验（含附件往返测试） | 第 8.1 节表 12 |
| `theory_check.py` | 排除体积判据、跃变中点、两种介质的边际效率 | 第 5.2 节、表 10 |
| `cluster_stats.py` | 最大团簇占比（渗流序参量） | 第 5.3 节、图 10 |
| `solve_p1.py` | 问题一：三个微构体的导通判定与稳健性 | 第 4 节表 2–表 4、图 5 |
| `solve_p2.py` | 问题二：四档体积分数的导通概率 | 第 5.2 节表 5、表 6 |
| `solve_p3.py` | 问题三：P≥90% 的最低体积分数 | 第 6.2 节表 7 |
| `solve_p4.py` | 问题四：网格取样、代理模型、候选点验证 | 第 7.2 节表 8、表 9 |
| `p4_backfill_probes.py` | 补记阶段 C 未通过的探测点（同种子复算） | 第 7.2 节表 9 |
| `p4_break_even.py` | 可行边界斜率与介质 B 的盈亏平衡单价 | 第 8.2 节 S3 |
| `geometry_bracket.py` | 球柱体近似的严格上下界（内接/外接球柱体） | 第 8.4 节表 16、表 17 |
| `p4_global_audit.py` | 成本下界的穷举式审计（预算线角点法） | 第 7.3 节表 11 |
| `p4_marginal_recheck.py` | 预算线擦边点的大样本复核（T=20000，独立种子） | 第 7.3 节 |
| `sensitivity.py` | 判据阈值、建模口径、样本量收敛 | 第 8.2、8.3 节表 13–表 15 |
| `sphere_mode_check.py` | 介质 B 越界处理口径的对照 | 第 9.2 节 |
| `paper_figures.py` | 全部正文图件（PNG + PDF 矢量） | 图 1–图 10 |
| `make_results_bundle.py` | 合并结果文件、装配论文附录 B | 附录 B |
| `build_paper_pdf.py` | 由 Markdown 终稿编译提交 PDF | — |

## 五、复现方式

```bash
cd 04_最终论文与代码交付包/src
python3 validate.py && python3 audit_attachment.py
python3 solve_p1.py && python3 solve_p2.py && python3 solve_p3.py && python3 solve_p4.py
python3 p4_backfill_probes.py && python3 p4_break_even.py && python3 theory_check.py
python3 sensitivity.py && python3 sphere_mode_check.py && python3 cluster_stats.py
python3 geometry_bracket.py && python3 p4_global_audit.py
python3 paper_figures.py && python3 make_results_bundle.py
python3 build_paper_pdf.py
```

依赖：Python ≥3.11 与 numpy / scipy / matplotlib / openpyxl；编译 PDF 另需
pandoc、texlive-xetex、texlive-lang-chinese。随机数由 `SeedSequence(20260810)`
按 worker 分叉，结果与并行度、运行时刻均无关，可逐位复现——
`p4_backfill_probes.py` 重算阶段 C 的探测点得到与原始运行完全相同的数值即是一次验证。
