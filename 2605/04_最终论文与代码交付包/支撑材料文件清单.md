# 支撑材料文件清单

对应论文《微构体中填充导电介质的仿真优化》。结果型数字均由 `src/` 下的脚本产出并记录到
`results/`；机械自检只作遗漏筛查，最终以“正文位置—结果键—生成脚本”的人工核对为准。

## 五、复现方式

```bash
cd 04_最终论文与代码交付包/src
python3 validate.py && python3 audit_attachment.py
python3 solve_p1.py && python3 solve_p2.py && python3 solve_p3.py && python3 solve_p4.py
python3 p4_backfill_probes.py && python3 p4_break_even.py && python3 theory_check.py
python3 sensitivity.py && python3 sphere_mode_check.py && python3 cluster_stats.py
python3 geometry_bracket.py && python3 p4_global_audit.py && python3 p4_marginal_recheck.py
python3 p4_global_audit2.py  # 可断点续跑；完整逐列审计耗时较长
python3 p4_pure_a_sweep.py
python3 p4_saa_search.py --lo 350268 --hi 352942 --a-max 624 --saa-target 0.92
python3 p4_low_a_outer_audit.py && python3 p4_build_global_certificate.py
python3 paper_figures.py && python3 make_results_bundle.py
python3 build_paper_pdf.py
```

依赖：Python ≥3.11 与 numpy / scipy / matplotlib / openpyxl；编译 PDF 另需
pandoc、texlive-xetex、texlive-lang-chinese。随机数由 `SeedSequence(20260810)`
固定分成 4 条随机流，worker 只负责调度；因此在 numpy 与算法版本相同的前提下，
结果与并行度、运行时刻均无关，可逐位复现。`scripts/test_parallel_reproducibility.py`
会以 1/2/4/8 个 worker 对同一配置做回归检查。
